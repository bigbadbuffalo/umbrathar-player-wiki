# Umbrathar Player Wiki

Player-facing lore for the **Umbrathar** sword-and-sorcery setting.

This public repository contains **generated publication output only**. The private Umbrathar setting workspace remains the canonical authoring source.

## Publication model

Private Obsidian/GitHub workspace → player-only export → privacy check → static site build → `gh-pages` branch in this repository → GitHub Pages.

Only articles explicitly marked `visibility: player` are eligible for publication. GM-only and spoiler-fenced material is stripped before the site is built.

Do not author setting canon directly in this repository; changes should be made in the private workspace and republished from there.
